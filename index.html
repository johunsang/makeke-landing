마케케 디자인

말로 만드는 디자인

원하는 디자인을 말하면 초안을 만들고, 화면에서 글자와 이미지를 직접 고칠 수 있습니다. 카드뉴스, 안내 이미지, 발표자료까지 한 곳에서 다룹니다.

광고 영상

광고 영상 만들기

상품이나 서비스 설명을 넣으면 광고 콘셉트, 장면, 음성, 자막, BGM을 묶어 영상 결과물로 만들 수 있습니다.

종합 콘텐츠

트렌드로 콘텐츠 만들기

무엇을 올릴지 막막할 때 실시간 트렌드와 검색 자료를 보고 바로 콘텐츠 제작으로 이어갈 수 있습니다.

기본 콘텐츠

필요한 것만 골라 만들기

블로그, 카드뉴스, SNS, 만화, 상세페이지 중 필요한 메뉴로 바로 들어가 만듭니다. 한 번에 전부 만들 필요가 없습니다.

작업 기록

만든 결과 다시 찾기

예전에 만든 글, 이미지, 영상, 디자인을 기록에서 다시 열고, 폴더를 열거나 다운로드해서 바로 사용할 수 있습니다.

관리

내 브랜드처럼 쓰기

프로필에 업체 정보, 문체, 로고, 참고 이미지를 넣어두면 AI가 매번 더 비슷한 톤으로 결과를 만듭니다.

How It Works

처음 써도 흐름은 단순합니다.

자료를 준비하고, 가져온 내용을 확인하고, AI가 만든 결과를 바로 복사하거나 저장하면 됩니다. 실패한 단계는 다시 시도할 수 있습니다.

1

주제 고르기

직접 입력하거나 뉴스, 블로그, URL, YouTube 자료를 고릅니다.

2

자료 확인

가져온 본문과 이미지를 눈으로 확인하고, 필요한 단계만 다시 시도합니다.

3

모델 확인

어떤 글 모델과 이미지 모델을 쓰는지 화면에서 먼저 확인합니다.

4

AI 생성

내 문체, 로고, 참고 이미지, 브랜드 정보를 반영해 결과를 만듭니다.

5

바로 사용

글은 복사하고, 이미지는 다운로드하고, 파일 위치를 바로 열 수 있습니다.

Content Details

카드뉴스와 이미지는 AI가 자연스럽게 구성합니다.

글자나 로고를 앱이 억지로 덧씌우지 않습니다. AI에게 주제, 본문, 로고, 참고 이미지를 알려주고 한 장 안에서 자연스럽게 만들도록 합니다.

  • 카드뉴스 1장부터 만들 수 있고 1:1, 4:5, 9:16, 16:9, 3:4, 4:3 비율을 공통으로 사용합니다.
  • 블로그 이미지 설정의 이미지 모델과 선택한 프로필 이미지를 사용하며, 영어 라벨과 가짜 워터마크를 금지합니다.
  • 만화 1회차 3컷이면 한 장 안에 3컷이 들어가도록 회차와 컷 수를 분리합니다.
  • 상세페이지 상품뿐 아니라 강의, 서비스, 병원, 매장, B2B 등 한국 업종 전반을 대상으로 만듭니다.
No More Confusion

헷갈렸던 부분을 정리했습니다.

예전 설명과 지금 앱이 달라 보이지 않도록, 사라진 기능과 바뀐 사용 방식을 홈페이지에서도 분명히 말합니다.

업로드 중심이 아닙니다

  • SNS 기본 흐름은 업로드가 아니라 복사 중심입니다.
  • 기본 콘텐츠 SNS 업로드 안내를 랜딩에서 제거했습니다.
  • 인스타·쇼츠·틱톡 자동 업로드를 핵심 가치로 말하지 않습니다.

보이는 기능만 말합니다

  • 브랜딩·이커머스·모델·패션·고급 도구는 현재 사이드바에서 숨김 상태입니다.
  • 39개 도구 문구를 현재 랜딩에서 제거했습니다.
  • 현재 보이는 마케케 디자인과 콘텐츠 제작 흐름을 앞에 둡니다.

메뉴가 쉬워졌습니다

  • 기본 콘텐츠 만들기는 블로그, 카드뉴스, SNS, 만화, 상세페이지 하위 메뉴로 바로 진입합니다.
  • 종합 콘텐츠 만들기는 실시간 트렌드와 직접 소재 발행으로 나뉩니다.
  • 기본 콘텐츠 기록에는 만화와 상세페이지가 포함되고 영상 탭은 제외됩니다.

Claude Design과 뭐가 다른가요?

FAQ

처음 쓰는 분들이 자주 묻는 질문

마케케를 처음 켰을 때 헷갈릴 수 있는 부분만 쉽게 답했습니다.

마케케는 자동 업로드 앱인가요?

아닙니다. 지금은 결과를 만들고 확인한 뒤 복사하거나 다운로드해서 쓰는 흐름이 중심입니다. 자동 업로드보다 내가 확인하고 바로 사용할 수 있는 결과를 만드는 데 집중합니다.

카드뉴스에 로고나 글씨를 앱이 억지로 붙이나요?

아닙니다. AI가 카드 한 장 안에서 글자, 그림, 로고를 자연스럽게 구성하도록 만듭니다.

내 문체는 어디에 적용되나요?

브랜드 프로필에 문체를 저장해두면 블로그와 SNS 글을 만들 때 우선 반영됩니다. 어떤 글 모델과 이미지 모델을 쓰는지도 화면에서 확인할 수 있습니다.

뉴스나 블로그 자료도 가져올 수 있나요?

네. 네이버 검색, URL, YouTube, 직접 입력을 사용할 수 있고, 가져온 본문과 이미지를 모달에서 확인할 수 있습니다.

사용료가 정말 0원인가요?

마케케 앱 사용료는 0원입니다. 완전 무료로 제공하며, 사용자가 직접 입력한 Gemini, Atlas 같은 API 키 비용이나 Codex, Kimi 같은 CLI/계정 사용량만 각 제공사 정책대로 부담합니다.

Claude Design 같은 작업을 더 유연하게 할 수 있나요?

마케케 디자인은 Claude Design을 그대로 복제하는 서비스가 아니라, 말로 디자인을 만들고 수정하는 방식을 마케케 안에 넣은 기능입니다. Gemini/Atlas API, Codex/Kimi CLI처럼 내가 가진 도구를 연결해 비용과 품질을 직접 선택할 수 있습니다.
