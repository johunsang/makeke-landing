무료 AI 마케팅 작업실

오늘 올릴 콘텐츠가 막혔다면, 마케케를 켜세요.

주제 찾기, 자료 수집, 글쓰기, 이미지 생성, 디자인, 기록 정리까지 한 앱에서 이어집니다. 마케케는 “언젠가 쓸 자동화”가 아니라 오늘 복사하고, 다운로드하고, 바로 쓸 결과물을 만드는 AI 마케팅 작업실입니다.

흩어진 마케팅 일이 한 화면에서 정리됩니다.

블로그 글을 쓰고, 카드뉴스를 만들고, SNS 문구를 정리하고, 상세페이지와 디자인까지 준비하는 일이 더 이상 따로 놀지 않습니다. 마케케는 오늘 필요한 결과를 한 자리에서 만들고 바로 가져갈 수 있게 돕습니다.

브랜드 경험

오늘 만들 콘텐츠가 눈앞에서 정리됩니다.

주제는 자료로 이어지고, 자료는 글과 이미지로 바뀌고, 완성된 결과는 복사와 다운로드로 바로 가져갑니다. 마케케는 마케팅 업무를 시작부터 결과까지 한 흐름으로 묶어줍니다.

자료 준비주제와 참고 자료가 한 화면에 모입니다.
AI 제작글, 이미지, 디자인이 같은 맥락으로 이어집니다.
바로 사용복사와 다운로드로 결과를 가져갑니다.
마케케를 켜면 다음 행동이 분명해집니다.무엇을 만들지 고르고, 자료를 넣고, 모델을 확인하고, 결과를 받아갑니다. 처음 쓰는 사람도 같은 흐름으로 블로그, 카드뉴스, SNS, 만화, 상세페이지를 시작할 수 있습니다.

실제 화면

말보다 화면이 빠릅니다.

설치 후 실제로 보게 되는 화면입니다. 콘텐츠를 만들고, 결과를 확인하고, 다시 꺼내 쓰는 과정을 눈으로 먼저 살펴보세요.

실제 생성 이미지

결과물이 많아질수록, 마케케의 가치가 더 잘 보입니다.

블로그 대표 이미지, 카드뉴스, 만화, 영상 썸네일까지 실제 생성 결과를 한 화면에 모았습니다. 소개 문구보다 먼저 결과를 보고 판단할 수 있게 구성했습니다.

결과 포트폴리오

설명보다 먼저, 실제 결과를 확인하세요.

마케케에서 만든 이미지와 영상을 원본으로 열어볼 수 있습니다. 화면만 그럴듯한 소개가 아니라, 실제 앱에서 생성된 결과를 먼저 확인할 수 있습니다.

실제 앱 캡처 카드뉴스 원본 블로그 이미지 원본 만화 원본 자동화 영상 광고 영상
마케케로 할 수 있는 일

한 가지 앱으로, 콘텐츠 업무의 앞뒤가 이어집니다.

여러 도구를 오가며 잃어버리던 시간을 줄이고, 오늘 필요한 콘텐츠를 같은 자리에서 완성하세요.

디자인 작업창

프롬프트를 넣고, 결과를 보며, 다시 고치는 작업 공간

마케케 디자인은 결과 이미지만 보여주는 메뉴가 아닙니다. 실제 작업창에서 설명을 입력하고, 참고 이미지를 붙이고, 생성 결과를 보며 이어서 수정합니다.

  • 작업창 안에서 입력, 모델 선택, 참고 이미지, 결과 확인이 이어집니다.
  • 피드, 스토리, 발표, 문서용 화면을 같은 흐름으로 만듭니다.
  • 마음에 든 결과는 기록에서 다시 열어 이어서 씁니다.
광고 영상

광고 메시지를 장면과 소리까지 이어주는 영상 흐름

상품이나 서비스를 짧은 광고 메시지로 바꾸고, 장면과 음성까지 이어서 영상으로 만듭니다.

  • 광고 카피가 화면과 소리로 이어집니다.
  • 완성 전 미리보고 어색한 부분을 줄입니다.
  • 완료된 영상은 다시 찾아 활용할 수 있습니다.
종합 콘텐츠

막막한 주제를 자료가 있는 콘텐츠로 바꾸기

트렌드, 네이버 자료, URL, YouTube 내용을 소재로 가져와 블로그와 카드뉴스의 출발점으로 씁니다.

  • 키워드 하나로 쓸 만한 소재를 빠르게 찾습니다.
  • 본문과 이미지를 함께 모아 글감으로 씁니다.
  • 하나의 소재를 블로그, 카드뉴스, SNS로 넓힙니다.
기본 콘텐츠

오늘 필요한 포맷만 골라 만드는 기본 콘텐츠

블로그, 카드뉴스, SNS, 만화, 상세페이지를 따로따로 고민하지 않아도 됩니다. 오늘 필요한 형식을 고르면 그에 맞는 결과를 받을 수 있습니다.

  • 블로그와 SNS는 내 브랜드 말투에 더 가까워집니다.
  • 카드뉴스는 글, 로고, 이미지가 한 장 안에 어울립니다.
  • 상세페이지는 상품, 강의, 서비스, 병원, 매장 소개까지 넓게 씁니다.
기록과 관리

한 번 만든 결과가 다음 작업의 자산이 됩니다

오늘 만든 글과 이미지는 다음 작업의 자산이 됩니다. 다시 찾고, 고치고, 비슷한 콘텐츠를 더 빠르게 이어갈 수 있습니다.

  • 블로그, 카드뉴스, SNS, 만화, 상세페이지 결과를 다시 봅니다.
  • 브랜드 정보와 문체를 저장해 매번 처음부터 설명하지 않습니다.
  • 원하는 결과에 가까워지도록 콘텐츠 방향을 계속 다듬습니다.

FAQ

처음 보는 분들이 바로 궁금해하는 것

처음 쓰는 분들이 가장 많이 묻는 내용을 모았습니다.

마케케는 어떤 앱인가요?

블로그, 카드뉴스, SNS, 만화, 상세페이지, 광고 영상, 디자인 작업을 한 곳에서 준비하는 무료 AI 마케팅 작업실입니다. 만든 결과는 복사하거나 다운로드하고, 기록에서 다시 찾을 수 있습니다.

정말 무료인가요?

마케케 앱 사용료는 0원입니다. 다만 사용자가 직접 등록한 Gemini, OpenAI, Anthropic, Moonshot/Kimi 같은 API 키 비용이나 Codex, Claude Code, Gemini, Kimi 계정/CLI 사용량은 각 제공사 정책을 따릅니다.

처음 시작하려면 무엇이 필요한가요?

마케케 설치 파일, 사용할 AI 모델의 API 키, 그리고 필요하면 Codex, Claude Code, Gemini CLI 같은 CLI 도구가 있으면 됩니다. 자세한 키 값과 CLI 설치 순서는 사용법 페이지에 정리되어 있습니다.

마케케 디자인은 결과물만 보여주는 기능인가요?

아닙니다. 마케케 디자인은 실제 작업창에서 프롬프트를 입력하고, 참고 이미지를 붙이고, 모델을 고르고, 결과를 보며 다시 수정하는 작업 공간입니다.

잘 나온 결과물은 어디서 볼 수 있나요?

이 페이지의 결과 포트폴리오 섹션에서 카드뉴스, 디자인 작업창, 상세페이지, 블로그, 만화, 광고 영상 예시로 바로 이동할 수 있습니다.

카드뉴스는 앱이 글자를 따로 덧씌우나요?

카드뉴스는 AI가 한 장의 완성 이미지로 만듭니다. 로고와 참고 이미지는 이미지 안에 자연스럽게 녹아듭니다.

로고는 어떻게 들어가나요?

프로필에 저장한 로고와 참고 이미지를 AI가 브랜드 요소로 참고합니다. 특정 위치에 억지로 붙이는 방식보다 이미지 안에 자연스럽게 어울리도록 쓰는 흐름을 권장합니다.

블로그와 SNS는 내 문체를 따라가나요?

브랜드 프로필에 저장된 문체를 우선 반영합니다. 블로그와 SNS 말투가 다르다면 프로필에서 각각의 문체를 더 구체적으로 저장하는 것이 좋습니다.

이미지도 만들 수 있나요?

네. 블로그 이미지, 카드뉴스, 만화 이미지, 상세페이지 이미지, 디자인 결과를 만들 수 있습니다. 생성 전에 어떤 이미지 모델을 쓰는지 화면에서 확인할 수 있습니다.

SNS는 자동 업로드되나요?

현재 핵심 흐름은 업로드가 아니라 복사 중심입니다. Threads와 X 글을 만들고, 필요한 문장을 복사해서 직접 게시하는 방식으로 사용합니다.

네이버 검색이나 URL 자료도 쓸 수 있나요?

네. 키워드 검색, URL 본문, 이미지, YouTube 분석 결과를 소재로 사용할 수 있습니다. 수집한 자료는 콘텐츠를 만들기 전에 화면에서 확인할 수 있습니다.

상세페이지는 상품만 가능한가요?

아닙니다. 상품, 강의, 서비스, 병원, 매장, B2B 소개처럼 다양한 업종과 목적에 맞춰 쓸 수 있습니다.

만든 결과는 어디에 저장되나요?
